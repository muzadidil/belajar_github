# belajar_github

Repositori untuk belajar menggunakan Git dan GitHub.

## Tentang

Proyek latihan untuk memahami alur kerja dasar Git & GitHub:

- `git init`, `git add`, `git commit`
- Menghubungkan folder lokal ke repositori remote
- `git push` dan `git pull`

## Mulai

```bash
git clone https://github.com/muzadidil/belajar_github.git
cd belajar_github
```
